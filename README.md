# Modern Portfolio – Kirithika R S

A modern, responsive personal portfolio website built with React, TypeScript, and Tailwind CSS. This portfolio showcases my profile, technical skills, projects, and professional journey through a clean and interactive user experience.

## 🚀 Technologies Used

- **Frontend Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Programming Language:** TypeScript

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Modern Dark Theme:** Elegant black-themed user interface.
- **Interactive Sidebar:** Smooth navigation with active section highlighting.
- **Animated Background:** Dynamic Galaxy background effects.
- **Smooth Animations:** Interactive transitions and hover effects using Framer Motion.
- **Single Page Application:** Smooth scrolling between portfolio sections.
- **Portfolio Sections:**
  - **Home:** Introduction and professional overview.
  - **About:** Personal introduction and background.
  - **Resume:** Education, experience, and technical skills.
  - **Portfolio:** Projects and development work.
  - **Contact:** Contact information and social media links.

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (Node Package Manager)

### Installation

1. Clone the repository:

```bash
git clone <your-github-repository-url>
```

2. Navigate to the project directory:

```bash
cd kirithika_Portfolio_main
```

3. Install dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

### Production Build

Build the project:

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.
